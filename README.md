# Aluno Mobile - Projeto Android Java

Projeto acadêmico baseado na proposta apresentada: aplicativo com duas funcionalidades principais, cálculo de média e cadastro de aluno com persistência local em SQLite.

## Funcionalidades
1. Cálculo de média de quatro notas: Prova 1, Prova 2, Trabalho e Atividade.
2. Cadastro de aluno com RA, nome e e-mail.
3. Persistência do cadastro usando SQLiteOpenHelper e DAO.
4. Validação de campos obrigatórios, e-mail e notas de 0 a 10.

## Como executar
Abra a pasta `AlunoMobile` no Android Studio, aguarde a sincronização do Gradle e execute em um emulador ou dispositivo Android.
